# Build the game in plain JavaScript and HTML5 Canvas instead of GDevelop

An early draft of the proposal named GDevelop. Instead, we build the game in plain JavaScript with no framework or build step. The pattern Figures are drawn on an HTML5 Canvas, and text and buttons are HTML on top. Drawing the Figures in code from their exact rules (mirroring, 60° rotation, regular polygons, Fibonacci spirals) keeps them mathematically exact in a way hand-placed sprites can't guarantee. Our developer already codes in JavaScript, and plain-text source files track cleanly in git, which also gives us our dated record of the work. The result is served for free from GitHub Pages as a public link. We give up GDevelop's visual editor, which matters little because only one member builds the game.

# Art exports

PNG exports of the game's maps and character sprites. The art itself is drawn in code in `game/js/draw.js` (pixel sprites, tiles, buildings), and these images were saved from it with `scripts/export-art.sh`. Run that script again after changing the art.

| File | What it shows |
| --- | --- |
| `characters.png` | Every character, in all four directions, standing and in both walking frames (16 × 16 px, shown 6×) |
| `map-town.png` | The Ateneo campus, the hub |
| `map-lab.png` | SOM 304, Sir Durwin's classroom in JGSOM |
| `map-garden.png`, `map-hive.png`, `map-field.png` | The three Levels |
